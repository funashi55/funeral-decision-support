## 作品名

sou-buddy（ソウ・バディ）

## 一文で

葬儀で担当者とご遺族の双方が迫られる、高額で取り返しのつかない意思決定と、覚えておくべきことをシステムに外出しして、担当者は寄り添いに、ご遺族はお別れに気持ちを向けられるようにする、担当者のスタイルに合わせて育つバディ。

## テーマ

テーマ1「あなたにしかない深さを」

## 概要（400字ほど）

葬儀では、担当者とご遺族の双方が複雑な意思決定を迫られます。ご遺族は、誰を呼ぶか、予算はいくらか、お墓はどこで誰が供養するかを、準備のないまま数日で決めます。担当者は、一件ずつ違うご家族に、抜け漏れなく、短い時間で最適な提案をしなければなりません。本当は、担当者は心の支えで信頼を得たいし、ご遺族は限られたお別れの時間をお別れに使いたいはずです。作者はフューネラルプランナーとして2年働き、家業も葬儀社です。

sou-buddy は、意思決定の支えと覚えておくべきことを、人の認知能力に頼らずシステムに外出しします。打合せの会話から事情と決まったことを拾い、取り返しのつかない見落としを先回りで知らせ、選択肢を根拠と実データの金額つきで並べます（費用を抑える案を必ず含め、金額は AI に作らせない）。打合せごとに記録を残し、ご家族に調べていただくこと・ご用意いただくことはスマホの窓口の TODO になります。支援の出し方は担当者のスタイルに合わせて育ちます。確定するのは人です。

## Claude の使い方

- 打合せの最中に出すもの（寄り添いの言葉・切り出し方・いまの見立て・話者の聞き分け・窓口の案内役）は Haiku 5.5。会話に追いつくことを優先し、推奨1回を Opus の 71秒から中央値 11.7秒にした
- 守る線（高いものへ誘導しない・不安をあおらない・多数派に合わせさせない）は、機械の検査と Opus 5.5 の判定役の二段で止める。落ちたら1回だけ出し直し、それでも落ちたら推奨を出さない
- 選択肢・配慮の考え方・注意は、モデルに文章を書かせず決まった一覧から ID を選ばせ、金額・割合・事実はサーバーが差し込む
- 打合せのあとの記録（要約・項目ごとの整理・文字起こしの清書）は Opus 5.5。決まったことはモデルに書かせず案件の決定から並べ、清書は元の文と並べて、ずれすぎたものは採らない
- 窓口の案内役は、記録を読む・検討メモを残す・担当者に回すの3つの道具しか持たない（決定を変える権限を道具の設計で持たせない）
- ロールプレイでは Claude がご遺族を演じ、ベテランと新人の尋ね方・決め方を記録に残す。Claude Code の Skill とサブエージェントで、聞き取りからベテランの知見を元の発言つきで取り出す
- 開発中は Claude Code のフックで、守る線に関わるファイルを編集するたびに検査を流した

## 確かめたこと

- 意地悪な場面20件（「お金は気にしない」「親戚の目」「発言に指示が紛れ込む」など）を実際のモデルで：20/20 合格。推奨を Haiku に替えた直後は 14/20 に落ちたので、少しだけ考えさせ、費用を抑えたいご家族向けの機械の検査を足して戻した。そのあと、グリーフケアと倫理の視点のレビューで見つかった抜け道（配慮の言葉が提案の前振りになる・口にしていない気持ちの決めつけ・ほのめかし）を判定役の基準に足し、合格16・表示しない4・すり抜け0（表示しないのは安全側の結果）
- 単体テスト 383件、E2E 29件（窓口に会話や AI の候補・見せていないお願いが漏れないこと、リンクの停止など）
