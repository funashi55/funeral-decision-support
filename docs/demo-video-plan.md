# デモ動画の計画（3分）v3

v2 からの変更：演者を立てない（画面の録画＋作者のナレーション）。いまの画面の流れ（ご家族の一覧 → 喪家の登録 → 寄り添い → 提案 → 手配 → ご家族の窓口）に合わせた。
家族・発言はすべて架空。金額は実データの集計値（品目ごとの中央値を丸めたもの）。実在の社名・人名・ロゴは出さない。

## 一本の筋

**「まず寄り添い、提案は信頼のあとで。その順番を、新人の隣で支える」**

同じ架空の家族（山田家：お風呂と庭の花が好きだった母、84歳。孫は東京から3日後に着く。費用は抑えたい）の打合せを最後まで追う。

## 撮り方

- **画面の録画はローカルで**：`cd web && npm run build && npx next start -p 3100`（開発用の「N」バッジが映らない）。1440×900。
- 撮る前に「最初から」を押して山田家を空にする。ガイドが出たら「閉じる」。
- モデルの出力は毎回変わるので3回撮り、寄り添いの言葉と提案がきれいに出た回を使う。1回の再生で AI を40〜60回呼ぶ（1日の上限は既定で3000回）。
- 窓口は Chrome の端末表示（Pixel 7）で撮る。
- `web/demo/*.record.ts`（Playwright）で自動で録ることもできる。
