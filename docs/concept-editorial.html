葬儀担当者のための、となりに座るベテラン

段取りに追われる時間を、
故人を想う時間へ。

ベテラン葬儀担当者が積み上げてきた「こういう時は、こうするといい」。その判断を、経験の浅い担当者の打合せにも届けます。遺族が決めることに追われる数日間を、別れのための時間に戻すための道具です。

打合せをその場で支える ベテランの知見を受け継ぐ 遺族がいつでも確かめられる

01　現場で見てきたこと

同じ打合せの中で、
三つのことが同時に起きている。

一

遺族

悲しみの中で、数日のうちに
重い決定を重ねなければならない

遺体を長く保てないため、葬儀は短い期間で進みます。プランと費用の内訳、日程と寺・火葬場の調整、親族への連絡。金額も小さくないので、迷い、悩み込んでしまう。故人らしさやお別れの形に、時間を使えていません。

二

葬儀担当者

一件ごとに事情が違い、
打合せの質が経験で決まる

ベテランと新人の差が出るのは、遺族の様子を読むこと、段取りの組み立て、要望と予算の調整。どれも、ベテランの頭の中にしかありません。

三

打合せのあと

担当者が何家族も抱え、
遺族は確認も検討も進められない

家族ごとの事情や決まったことは、担当者の記憶と紙の打合せシートにしか残っていません。「明日は何時にどこへ」「花を変えたらいくら」。聞きたいことがあっても、担当者がつかまるまで待つしかありません。

本来は、故人らしさや、どういうお別れをしたいかに時間をじっくりかけてほしい。けれど実際は、親族や日程の調整、金額のことで考え悩んでしまっている。 — 作者（葬儀社勤務の経験あり、家業も葬儀関係）

02　足りないもの

ベテランの判断は、
言葉にも、道具にもなっていない。

  • 今日決めなくていいことは、明日に回す
  • この家族には、まず安いプランから見せる
  • この宗派なら、寺への連絡を先に
  • 呼ばれなかった親族が、後で揉める

ベテランの頭の中にある「こういう時は、こうする」

道具にする

足りないのは、二つ。

  1. ベテランの判断を、新人が打合せのその場で使える形にしたもの
    会話を聞き取り、根拠つきで推奨を示す担当者の画面
  2. その家族の記録を、遺族がいつでも確かめられる窓口
    スマホで確認・相談・検討ができ、確定は担当者が行う

03　しくみ

打合せの会話から、
担当者と遺族の両方に届く。

04　画面のイメージ

新人の打合せの隣で、
ベテランがそっと耳打ちする。

05　安心して使うための約束

弱っている人の隣で使う道具だから、
守る線を、仕組みにする。

廉

高いプランへ誘導しない

推奨には必ず予算を抑える選択肢を含めます。出す前に判定役が検査し、外れていれば出し直します。

拠

推奨には根拠を添える

会話のどの発言と、どの知見に基づくかを示します。納得できない推奨は、使わなくて構いません。

人

確定は人が行う

遺族の窓口でできるのは確認・相談・検討まで。変更や確定は、担当者が内容を確かめてから行います。

秘

録音は同意制、音声は残さない

開始前に遺族の同意を取り、要点の記録だけを残します。窓口は推測できない URL と確認コードで開きます。

06　Claude の使い方

役割ごとに、Claude の使い方を変える。

速さが要る場面、判断の質が要る場面、権限を絞りたい場面。目的に合わせて、モデルと機能を使い分けます。

一　受け継ぐ

ベテランの話を、知見に変える

聞き取りの記録を、テーマ別のサブエージェントが並行して読み、「こういう時はこうする＋元の発言」に抽出します。

Claude Code ／ サブエージェント ／ Skills
二　聞き取る

会話から、事実と保留を拾う

打合せのテンポに遅れないよう、軽く速いモデルで少しずつ拾い上げます。

Haiku 5.5
三　耳打ちする

ベテラン流の推奨を出す

会社ごとの知見 Skill を読み込み、根拠を必ず添えて推奨します。

Opus 5.5 ＋ 知見 Skill
四　確かめる

守る線を外していないか検査

高いプランへの誘導がないか、安い選択肢を示したか。開発中もフックで同じ検査を回します。

判定役 ／ Claude Code フック
五　寄り添う

遺族の窓口を、家族ごとに

使える道具は「記録を読む」「検討メモを残す」「担当者に回す」の三つだけ。確定の権限を持たせません。

Managed Agents

07　ハッカソンのあとも

使うほど、その会社の知見が厚くなる。

最初に使うのは、作者の家業の葬儀社です。

知見は、親族のベテランへの聞き取りと作者自身の現場経験から作ります。だから道具には、その会社の流儀がそのまま入ります。

施行のあと、担当者は「推奨は役に立ったか、違う判断をしたか」を一言残します。その記録で知見が更新され、ベテランが引退した後も、判断は会社に残り続けます。

決めることは、短く。
別れは、ゆっくり。
